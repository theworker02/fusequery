# fusequery

Fuse digests and query fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/fusequery/

## Install / run

```bash
git clone https://github.com/theworker02/fusequery.git
cd fusequery
node src/cli.js
node --test
```
